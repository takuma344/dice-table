# 幸運のダイステーブル（Dice Table）

ダイスを振ってコインを集め、自動化と恒久強化でテーブルを育てるブラウザ向け放置ゲームです。描画は HTML5 Canvas、効果音は Web Audio API を使用しています。ゲームはブラウザ内で完結し、依存パッケージやビルド作業は不要です。

## 遊び方

| 操作 | PC | スマホ |
| --- | --- | --- |
| ダイスを振る | ダイスをクリック | ダイスをタップ |
| 強く投げる | ダイスを長押し、またはダイスからドラッグして離す | ダイスを長押し、またはダイスからフリック |
| テーブルスラム | 動いているダイスの近くのフェルトをクリック | 動いているダイスの近くのフェルトをタップ |
| ホールド | 「ホールド」を押して止まったダイスを選ぶ | 同左 |
| キーボード | Spaceで投擲、Hでホールド選択、Sでスラム。テーブルにフォーカス中はEnterでも投擲・選択 | |

最初はコイン0枚、木製ダイス1個から始まります。2個目は9コインです。「アップグレード」タブでダイスやアームを増やし、「VIP」タブで転生や恒久強化を管理します。効果音は右上のボタンで切り替えられます。

### ホールド、スラム、大共鳴

- ダイスを押したまま蓄力し、引いた方向に離すと強く投げられます。表示されるリングと矢印で力と方向を確認できます。空いているフェルトからダイスを横切るドラッグ・スワイプでも弾けます。
- スラムは短辺の30%以内にあるダイスを最大3個再投擲します。再使用は2.5秒後です。投擲中か停止直後のダイスが対象で、ホールド中は周囲の静止したダイスも対象にできます。
- ホールドできるのは1個・14秒間です。点線の円内でスラムしたダイスは固定した目に揃いやすく、外れた後の狙い直しでは揃うようになります。揃うと大共鳴で追加配当とフィーバーゲージを獲得し、固定が解除されます。
- 初回周回の45ロールまでは、手動投擲でもゲージがたまり、共鳴と大共鳴でも通常より多く充填します。

## ゲームシステム

- **ロールと衝撃波**。ダイスは高さを持ち、着地や木枠で跳ね返ります。22コインで手動の衝撃波を解放すると、ダイスを振ったときに近くのダイスも巻き込みます。スラムは最初から使える別操作です。
- **共鳴とフィーバー**。0.8秒以内に同じ出目がそろうと共鳴ボーナスとフィーバーゲージを獲得します。同じ手動衝撃波でそろえると追加ボーナスが付きます。ゲージが満タンになると「黄金の狂熱タイム」が10秒間発動し、獲得コインは2倍、アームの投擲間隔は半分になります。
- **材質強化**。木製・象牙・黄金・ネオンレーザーの基礎倍率は順に ×1・×3・×9・×28です。材質は1個ずつ強化します。黄金以上への進化には「材質ライセンス」が必要です。ネオンレーザーには通算1回以上のVIP転生も必要です。進化には全ダイスを前段階以上にそろえます。
- **自動化**。アームは通常1作動につきダイス1個を振ります。VIPタレントで近接連鎖やアーム衝撃波を解放できます。
- **VIP転生**。その周回で40,000コインを獲得すると転生できます。星を含む通常進行をリセットしてVIPチップを獲得し、タレントとテーブルスキンを維持します。タレントでスタート時の所持コイン、収益、共鳴、自動化などを強化できます。「材質の下地」は取得直後から新規ダイスの材質に反映されます。

### 特殊ダイス

ダイスを3個以上所持すると、アップグレードパネルの「特殊ダイス」が利用できます。番号が最も大きい★1の通常ダイスをコインで変換し、材質を引き継ぎます。各種類は同時に4個まで所持でき、所持数に応じて次の変換価格が上がります。ダイスの総数は変わらず、上限は40個です。VIP転生で変換はリセットされます。

| 種類 | 1個目の価格 | ★1の効果 |
| --- | ---: | --- |
| **爆裂ダイス**（爆） | 650 | 出目5・6で爆裂波が発生し、周囲のダイスを弾きます。爆裂波で振られたダイスからの再爆発はありません。 |
| **増幅ダイス**（増） | 950 | 静止中は緑の円で示す範囲内に着地した他のダイスの配当を25%増やします。共鳴ボーナスにも適用されます。 |
| **熱気ダイス**（熱） | 850 | 出目4〜6でフィーバーゲージに6ポイント加算します。フィーバー中の追加充填はありません。 |

### ダイス合成・星上げ

「ダイス合成」に、材質・特殊タイプ・星がすべて同じ組み合わせと合成後の効果が表示されます。「合成する」を押すと、投擲中でもすぐに次の星のダイス1個になります。合成に使った投擲は終了し、空いた枠にはダイスを購入できます。

購入価格は、その周回で取得したダイスを合成前の個数に換算して決まります。★1・★2・★3・★4をそれぞれ1・2・4・8個分と数えるため、合成で枠が空いても価格は下がりません。VIP転生後は、新しい周回の初期ダイス数から価格を計算します。旧セーブも記録済みの星から同じ方法で計算します。

| 星 | 材質配当にかかる倍率 | 着地波で再投擲 | 爆裂波の基礎半径 | 増幅の追加配当 | 熱気の追加ゲージ |
| --- | ---: | ---: | ---: | ---: | ---: |
| ★1 | ×1 | — | テーブル短辺の16% | ＋25% | ＋6ポイント |
| ★2 | ×3.25 | 最大1個 | 23.5% | ＋60% | ＋13ポイント |
| ★3 | ×9.5 | 最大2個 | 32% | ＋110% | ＋22ポイント |
| ★4（上限） | ×28 | 最大4個 | 39.5% | ＋180% | ＋34ポイント |

★2以上は大きくなり、星・オーラリング・投擲時の軌跡で見分けられます。強化タブのバッジは投擲中を含む合成可能なペア数を示します。合成すると対象のダイスがテーブル中央に集まり、光と効果音で結果を表示します。

★2以上は着地時にフィーバーゲージも増やします。着地波で振られたダイスは元のダイスと出目が揃いやすく、共鳴すると追加ボーナスが付きます。着地波や爆裂波で振られたダイスからは次の波が発生しません。

爆裂ダイスは星が高いほど少ない出目で発動し、発動時は着地波の代わりに爆裂波が出ます。爆裂波の半径は手動衝撃波のレベルでも伸びます。増幅は星とともに範囲が広がり、★3以上では範囲内の着地がフィーバーも充填します。増幅範囲が重なると最も強い効果が適用されます。熱気は星が高いほど多くの出目で充填でき、★3以上はフィーバー中の配当も上がります。

### バーストとネオンマスタリー

フィーバー中、★3以上・共鳴コンボ4以上・特殊効果のうち2つが同じロールで重なると、フィーバー配当倍率が通常の×2から×4に上がります。3つとも重なると×6です。バーストしたロールにはテーブル上に倍率が表示されます。

VIP転生3回でサイバーネオンが解放されると、VIPタブに3つのマスタリー目標が現れます。ネオンレーザーの★4、特殊ダイスの★4、1回のフィーバーで8回のバーストを達成すると、それぞれVIPチップがもらえます。全達成でオーロラブラックを使えるようになります。達成状況は転生後も引き継がれます。

### 図鑑・実績とマイルストーン

「図鑑」タブでは、材質、特殊ダイス、到達した星、テーブルスキンの収集状況を確認できます。入手した要素は転生後も図鑑に残ります。

累計ロール、最大共鳴コンボ、フィーバー発動、累計合成、到達した星、VIP転生、図鑑収集にはそれぞれ3段階の実績があります。達成すると通知が表示され、報酬は自動で加算されます。すべて達成したとき、獲得コインは最大＋12%、共鳴ボーナスとフィーバー充填はそれぞれ最大＋6%です。「統計」では、1回のフィーバーでの最高獲得コインと最多バーストも確認できます。

旧セーブでは、現在の所持状況、解放済みスキン、累計ロールや最大コンボ、残っている星から分かる最少の合成回数を反映します。過去のフィーバー獲得額など、旧セーブに記録がない値は導入後のプレイから記録します。

### セーブ

進行はブラウザの `localStorage` に自動保存されます。星が未記録の旧セーブは、既存の材質・特殊タイプを維持したまま各ダイスを★1として読み込みます。同じブラウザでも、ローカル起動と公開サイトのセーブはそれぞれの保存領域を使用します。ゲーム内の「データをリセット」で初期状態に戻せます。

アームを雇用していると、離れていた時間に応じた放置収益を最大4時間分受け取れます。特殊ダイスの効果はプレイ中に発動します。

## ローカルで起動

リポジトリをクローンするかダウンロードし、`index.html` をブラウザで開きます。HTTPで試す場合は、Pythonをインストール済みの環境でプロジェクトルートから次のコマンドを実行し、[ローカルのゲーム](http://localhost:8000/) を開きます。

```sh
python -m http.server 8000
```

## GitHub Pagesで公開

1. `index.html`、`style.css`、`game.js` をリポジトリの `main` ブランチにプッシュします。
2. GitHubのリポジトリで **Settings → Pages** を開きます。
3. **Build and deployment** の **Source** で **Deploy from a branch** を選びます。
4. ブランチに `main`、フォルダに `/(root)` を指定し、**Save** を押します。
5. デプロイが完了したら、**Settings → Pages** に表示される公開URLを開きます。

[GitHub Pagesの公開元を設定する（GitHub Docs）](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)
