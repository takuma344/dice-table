# 幸運のダイステーブル（Dice Table）

ダイスを振ってコインを集め、自動化と恒久強化でテーブルを育てるブラウザ向け放置ゲームです。描画は HTML5 Canvas、効果音は Web Audio API を使用しています。ゲームはブラウザ内で完結し、依存パッケージやビルド作業は不要です。

## 遊び方

| 操作 | PC | スマホ |
| --- | --- | --- |
| ダイスを振る | ダイスをクリック | ダイスをタップ |
| ダイスを続けて弾く | ダイスを横切るようにドラッグ | ダイスを横切るようにスワイプ |
| キーボードで振る | Space、またはテーブルにフォーカスして Enter | |

最初はコイン0枚、木製ダイス1個から始まります。「アップグレード」タブでダイスやアームを増やし、「VIP」タブで転生や恒久強化を管理します。効果音は右上のボタンで切り替えられます。

## ゲームシステム

- **ロールと衝撃波**。ダイスは高さを持ち、着地や木枠で跳ね返ります。26コインで手動の衝撃波を解放すると、ダイスを振ったときに近くのダイスも巻き込みます。
- **共鳴とフィーバー**。0.8秒以内に同じ出目がそろうと共鳴ボーナスとフィーバーゲージを獲得します。同じ手動衝撃波でそろえると追加ボーナスが付きます。ゲージが満タンになると「黄金の狂熱タイム」が10秒間発動し、獲得コインは2倍、アームの投擲間隔は半分になります。
- **材質強化**。木製・象牙・黄金・ネオンレーザーの基礎倍率は順に ×1・×3・×9・×28です。材質は1個ずつ強化します。黄金以上への進化には「材質ライセンス」が必要です。ネオンレーザーには通算1回以上のVIP転生も必要です。進化には全ダイスを前段階以上にそろえます。
- **自動化**。アームは通常1作動につきダイス1個を振ります。VIPタレントで近接連鎖やアーム衝撃波を解放できます。
- **VIP転生**。その周回で40,000コインを獲得すると転生できます。星を含む通常進行をリセットしてVIPチップを獲得し、タレントとテーブルスキンを維持します。タレントでスタート時の所持コイン、収益、共鳴、自動化などを強化できます。「材質の下地」は取得直後から新規ダイスの材質に反映されます。

### 特殊ダイス

ダイスを3個以上所持すると、アップグレードパネルの「特殊ダイス」が利用できます。番号が最も大きい★1の通常ダイスをコインで変換し、材質を引き継ぎます。各種類は同時に4個まで所持でき、所持数に応じて次の変換価格が上がります。ダイスの総数は変わらず、上限は40個です。VIP転生で変換はリセットされます。

| 種類 | 1個目の価格 | ★1の効果 |
| --- | ---: | --- |
| **爆裂ダイス**（爆） | 650 | 出目5・6で爆裂波が発生し、周囲のダイスを弾きます。爆裂波で振られたダイスからの再爆発はありません。 |
| **増幅ダイス**（増） | 950 | 静止中は緑の円で示す範囲内に着地した他のダイスの配当を25%増やします。共鳴ボーナスにも適用されます。 |
| **熱気ダイス**（熱） | 850 | 出目4〜6でフィーバーゲージに6ポイント加算します。フィーバー中の追加充填はありません。 |

### ダイス合成・星上げ

「ダイス合成」に、材質・特殊タイプ・星がすべて同じ組み合わせが表示されます。2個が着地したら「確認」を開いて対象と効果を確認し、「合成する」を押します。元の2個から次の星のダイス1個ができ、空いた枠にダイスを購入できます。

| 星 | 材質配当にかかる倍率 | 爆裂波の基礎半径 | 増幅の追加配当 | 熱気の追加ゲージ |
| --- | ---: | ---: | ---: | ---: |
| ★1 | ×1 | テーブル短辺の16% | ＋25% | ＋6ポイント |
| ★2 | ×2.35 | 20% | ＋37% | ＋9ポイント |
| ★3 | ×5.5 | 24% | ＋49% | ＋12ポイント |
| ★4（上限） | ×13 | 28% | ＋61% | ＋15ポイント |

爆裂波の半径は手動衝撃波のレベルでも伸びます。増幅は星が上がるほど広がり、複数の円が重なる場所では最も強い効果が適用されます。ダイスを多く並べると同時着地や共鳴の機会が増え、合成で星を上げると1ロールの配当と特殊効果が伸びます。★2以上はテーブル上に星が表示されます。

### セーブ

進行はブラウザの `localStorage` に自動保存されます。星が未記録の旧セーブは、既存の材質・特殊タイプを維持したまま各ダイスを★1として読み込みます。同じブラウザでも、ローカル起動と公開サイトのセーブはそれぞれの保存領域を使用します。ゲーム内の「データをリセット」で初期状態に戻せます。

アームを雇用していると、離れていた時間に応じた放置収益を最大4時間分受け取れます。特殊ダイスの効果はプレイ中に発動します。

## ローカルで起動

リポジトリをクローンするかダウンロードし、`index.html` をブラウザで開きます。HTTPで試す場合は、Pythonをインストール済みの環境でプロジェクトルートから次のコマンドを実行し、[ローカルのゲーム](http://localhost:8000/) を開きます。

```sh
python -m http.server 8000
```

## GitHub Pagesで公開

1. `index.html`、`style.css`、`game.js` をリポジトリの `main` ブランチにプッシュします。
2. GitHubのリポジトリで **Settings → Pages** を開きます。
3. **Build and deployment** の **Source** で **Deploy from a branch** を選びます。
4. ブランチに `main`、フォルダに `/(root)` を指定し、**Save** を押します。
5. デプロイが完了したら、**Settings → Pages** に表示される公開URLを開きます。

[GitHub Pagesの公開元を設定する（GitHub Docs）](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)
