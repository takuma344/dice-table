# 幸運のダイステーブル（Dice Table）

ダイスを振ってコインを集め、自動化と恒久強化でテーブルを育てるブラウザ向け放置ゲームです。描画は HTML5 Canvas、効果音は Web Audio API を使用しています。ゲームはブラウザ内で完結し、依存パッケージやビルド作業は不要です。

## 遊び方

| 操作 | PC | スマホ |
| --- | --- | --- |
| ダイスを振る | ダイスをクリック | ダイスをタップ |
| 投げる方向を決める | ドラッグして離す | フリック |
| 強く投げる | ダイスを長押しして離す | 同左 |
| キーボード | Spaceで投擲。テーブルにフォーカスしているときはEnterでも投擲 | — |

最初はコイン0枚、木製ダイス1個から始まります。投擲方向はダイスの軌道に影響します。空いているフェルトからダイスを横切るドラッグやスワイプでも弾けます。効果音は右上のボタンで切り替えられます。

投擲中はダイスの後ろに材質や特殊タイプの色の軌跡が残ります。枠に当たると朱色、ダイス同士が強くぶつかると青緑の火花が出ます。着地時の金色の粒と「＋」の金額はコイン獲得の目印です。端末で「視差効果を減らす」などの設定を有効にすると、軌跡やこれらの追加エフェクト、購入時のバウンスを省きます。

## ショップ・強化・スキルツリー

| タブ | 初期状態 | スキル解放後 |
| --- | --- | --- |
| **ダイスショップ** | 通常ダイスの販売と「スキルツリー解放」。2個目のダイスは9コイン | 習得した種類の特殊ダイスを追加購入できます |
| **強化** | 「基礎収益アップ」のみ。最初は30コイン、1レベルにつき基礎配当＋35% | 品質、材質、アーム、衝撃波、合成を習得に応じて表示します |
| **スキルツリー** | ロック中 | ショップで1,000コインを支払うと開きます。コインと前提スキルに応じて新機能や強化を習得します |

スキルツリーの解放は一度だけです。ダイス、強化、習得したスキルを使いながら同じテーブルで進めます。スキル習得で商品や強化が追加される場合は、該当タブで購入して効果を有効にします。

### スキルに投資する

スキルツリーを解放したら、ダイス品質（1,200コイン）、共鳴（1,000）、手動衝撃波（1,400）、ロボットアーム（1,800）から選べます。ノードを選ぶと、効果・レベル・次の価格・必要条件が詳細カードに表示されます。接続線が親ノードを示し、点線の接続は上位レベルで加わる条件です。スマホでは横にスワイプするか、上部のルート名で見たい位置に移動できます。

| 系統 | 次の投資の目安 |
| --- | --- |
| **共鳴・フィーバー** | 共鳴から共鳴配当とフィーバーに分岐します。フィーバーを習得するには共鳴3回が必要です。共鳴配当の上位ランクは最大コンボ、熱気の蓄積はフィーバー発動回数が条件です。 |
| **材質・合成** | ダイス品質から材質加工と合成に分岐します。銅製を図鑑に登録すると鉄の材質加工（24,000）、鉄製を登録すると金の材質加工（320,000）に進めます。合成の習得にはダイス2個分が必要です。 |
| **自動化** | ロボットアームの習得と雇用を経て、速度→近接連鎖の順に進みます。アーム衝撃波（240,000）には近接連鎖Lv.2と有効化済みの手動衝撃波が必要です。 |
| **特殊ダイス** | 爆裂は手動衝撃波、増幅は合成、熱気は熱気の蓄積から解放します。増幅の上限4・5個には材質加工Lv.2も必要です。所持上限を上げるには対象の種類を現上限の個数分まで購入します。合成済みのダイスは合成前の個数で数えます。 |

習得済みのスキルと所持上限はセーブからそのまま復元します。既存の習得効果はそのまま使えます。新しい前提条件は次回の習得・強化から適用されます。

プレイテスト版では、アーム初雇用は420コイン、速度の初強化は650コイン、手動衝撃波の有効化は240コインです。スキルの習得費用と実際に稼働させる費用を合わせて投資先を選べます。

### ダイスとテーブルの強化

- **品質と材質**。品質は出目5・6の配当を1レベルにつき15%伸ばします。材質倍率は木製×1、銅製×3、鉄製×9、金製×28です。「材質加工」Lv.1〜3で進化できる材質が増えます。材質強化は最も下位の通常ダイスから1個ずつ適用し、価格は対象の星、通常ダイスの内訳と進化状況に応じて上がります。「材質の下地」は新しく購入する通常ダイスの初期材質を上げます。
- **ロボットアーム**。アームを雇うと、一定間隔でダイスを自動で振ります。速度強化、近接ダイス連鎖、アーム衝撃波はそれぞれスキルで解放します。
- **手動衝撃波**。スキルを習得し、強化で有効化すると、ダイスを手動で振ったときに近くのダイスも巻き込みます。追加強化で範囲が広がります。
- **共鳴**。習得後は、0.8秒以内に同じ目が着地すると追加配当が出ます。同じ手動衝撃波で振ったダイスや、方向付きの投擲、特殊効果と組み合わせると配当が伸びます。
- **フィーバー**。共鳴の習得後に解放できます。共鳴や特殊効果などで満タンになると、10秒間コイン配当が2倍、アーム作動間隔が半分になります。ゲージの獲得効率もスキルで強化できます。

### 特殊ダイス

種類ごとにスキルを習得して、ショップで通常ダイスとは別に購入します。購入するたびにテーブルへ1個追加されます。各種類の初期上限は1個で、その種類のスキルを上げると1個ずつ増え、最大5個になります。通常・特殊を合わせたテーブル上限は40個です。

特殊ダイスは専用の外装を持ち、材質内訳・強化・合成の対象外です。材質倍率は等倍です。爆裂は黒赤の外殻と火色の亀裂、増幅は青緑の外殻と環状の導線、熱気は琥珀色の外殻と立ち上る炎を描いています。

旧セーブからは所持数、合成済みの星とその効果、合成前換算の個数、習得済みスキルや達成済みマスタリーを引き継ぎます。旧特殊ダイスの材質枠は読み込み時に空欄にし、配当にも材質倍率は適用されません。

| 種類 | 基準価格 | ★1の効果 |
| --- | ---: | --- |
| **爆裂ダイス**（爆） | 800 | 出目5・6で爆裂波を放ち、周囲を弾く |
| **増幅ダイス**（増） | 1,150 | 静止中、緑の円の中に着地した他のダイスの配当を25%増やす |
| **熱気ダイス**（熱） | 1,000 | 出目4〜6でフィーバーを6ポイント充填する |

### 合成とフィーバーバースト

「ダイス合成」スキルを習得すると、強化タブに材質と星が同じ通常ダイスのペアが表示されます。コインで2個を次の星の1個に合成でき、投擲中のダイスも対象です。通常ダイスの購入価格は現在の通常ダイスを合成前の個数に換算して決まり、合成して枠が空いても下がりません。特殊ダイスの価格は種類ごとの合成前の個数とテーブル全体の進行度で決まります。

旧セーブの合成済み特殊ダイスには、表の爆裂・増幅・熱気の効果が引き継がれます。

| 星 | 基礎配当にかかる倍率 | 着地波で再投擲 | 爆裂波の基礎半径 | 増幅の追加配当 | 熱気の追加ゲージ |
| --- | ---: | ---: | ---: | ---: | ---: |
| ★1 | ×1 | — | テーブル短辺の16% | ＋25% | ＋6ポイント |
| ★2 | ×2.65 | 最大1個 | 23.5% | ＋60% | ＋13ポイント |
| ★3 | ×6.9 | 最大2個 | 32% | ＋110% | ＋22ポイント |
| ★4（上限） | ×18 | 最大4個 | 39.5% | ＋180% | ＋34ポイント |

★2以上は星とオーラが付き、着地波で近くのダイスを再投擲します。共鳴の習得後は、着地波に巻き込まれたダイスが元のダイスと同じ目を出しやすくなります。フィーバーの習得後は、★2以上の着地でもゲージを充填できます。フィーバー中に「★3以上」「共鳴コンボ4以上」「特殊効果」のうち2つが同じロールで重なるとバースト×4、3つなら×6になります。

### 図鑑・実績・テーブルスキン

図鑑には発見した材質、特殊ダイス、星、テーブルスキンが残ります。投擲・共鳴・フィーバー・合成・スキル・収集の実績を達成すると、収益や充填効率への小幅な恒久報酬が自動で加わります。

累計1万コインでロイヤルレッド、15万コインでサイバーネオンが解放されます。金製★4、同種の特殊ダイス4個分の収集、1回のフィーバーで8回のバーストを達成するとオーロラブラックが使えます。スキンは図鑑で切り替えます。

## セーブと旧バージョンとの互換性

進行は同じブラウザの localStorage に自動保存されます。アームを雇っていると、離れていた時間に応じて最大4時間分の放置収益を受け取れます。手動リセットは統計パネルにあります。

旧セーブのダイス・コイン・記録・スキンを引き継ぎ、材質は旧ランクと同じ段階に読み替えます。購入済みの機能やプレイ記録から必要なスキルを復元します。未使用の旧VIPチップと、旧「準備金」「予備ダイス」に使ったチップは1枚につき250コインに一度だけ換算します。星が未記録のダイスは★1です。

## ローカルで起動

リポジトリをクローンするかダウンロードし、`index.html` をブラウザで開きます。HTTPで試す場合は、Pythonをインストール済みの環境でプロジェクトルートから次のコマンドを実行し、[ローカルのゲーム](http://localhost:8000/) を開きます。

```sh
python -m http.server 8000
```

## GitHub Pagesで公開

1. `index.html`、`style.css`、`game.js` をリポジトリの `main` ブランチにプッシュします。
2. GitHubのリポジトリで **Settings → Pages** を開きます。
3. **Build and deployment** の **Source** で **Deploy from a branch** を選びます。
4. ブランチに `main`、フォルダに `/(root)` を指定し、**Save** を押します。
5. デプロイが完了したら、**Settings → Pages** に表示される公開URLを開きます。

[GitHub Pagesの公開元を設定する（GitHub Docs）](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

## ピクセルアートとエフェクト

盤面は CSS 1px を基準に、フェルトの織り目、木枠の段差、ダイスの面取り、アームの板金とねじを描いています。ショップの値札、タブ、カードは木・真鍮・紙を共通の色で表現し、パネルには角の大きさを保つ9スライス枠を使用しています。配当や共鳴の日本語ラベルは画面解像度で描きます。 配当は暗い縁取り付きの数字で表示し、共鳴はミント色、バーストは金色で強調します。共鳴したダイスの周囲に光の粒が広がり、ダイス間をスパークが伝わります。盤面が混み合うと、共鳴額やバースト倍率を優先し、置けない場合は盤面上部に表示します。

投擲・衝突、着地のコイン、共鳴、爆裂、フィーバーには pixelfx から書き出した透過スプライトシートを使用します。衝撃波は元の範囲に沿ってドットのリングで描き、購入・解放はボタンと購入結果を段階的に光らせます。モーション軽減を有効にすると追加の点滅とスプライト演出を抑えます。

使用素材は `impacts/hit-spark`、`impacts/crit-hit`、`pickups/coin-spin`、`explosions/plasma-explosion`、`arcane/mana-burst` です。後者2種は色を調整して書き出しました。MIT ライセンスは [art/pixelfx/LICENSE.txt](art/pixelfx/LICENSE.txt) にあります。[pixelfx の素材元](https://github.com/patch-gg/pixelfx/tree/5294518ce7c72e48b6100a744596e0acf57f2826)
